# دسترسی راه دور موسسه

نرم‌افزار کنترل از راه دور اختصاصی **موسسه تحقیقات سیاست علمی کشور**
ساخته‌شده روی هستهٔ متن‌باز راست‌دسک، با هویت بصری، نام و ظاهر موسسه.

---

## ⬅ چطور به فایل نصبی برسیم (مهم‌ترین بخش)

فایل نصبی ویندوز باید روی یک ماشین ویندوزی کامپایل شود. سه راه دارید:

| راه | نیاز دارد | زمان |
|---|---|---|
| **ابری (پیشنهاد من)** | فقط یک حساب رایگان گیت‌هاب | حدود یک ساعت، خودکار |
| کامپیوتر خودتان | ویندوز + ویژوال استودیو + ابزارهای بخش ۲ | حدود دو ساعت |
| سرور ویندوزی | همان‌ها روی سرور | حدود دو ساعت |

راه ابری رایگان است و هیچ چیزی روی کامپیوتر شما نصب نمی‌کند.
راهنمای گام‌به‌گام: **[docs/5-cloud-build.md](docs/5-cloud-build.md)**

خلاصهٔ کار:

۱. فایل `NRISP-Remote-Project.zip` را دانلود و از حالت فشرده بیرون بیاورید
۲. در گیت‌هاب یک مخزن عمومی بسازید و محتویات پوشه را در آن بارگذاری کنید
۳. تب Actions → «ساخت نرم‌افزار دسترسی راه دور موسسه» → Run workflow
۴. بعد از حدود یک ساعت، فایل نصبی در بخش Artifacts آماده است

یا اگر `git` و `gh` دارید، تنها یک فرمان:

```bash
bash tools/push-to-github.sh
```

## دو: دو فرمان تا فایل نصبی

روی کامپیوتر ساختمان (ویندوز با پایتون و ابزارهای بخش ۲ راهنما):

```bash
# ۱. سورس راست‌دسک را بگیرید
git clone --depth 1 --recurse-submodules https://github.com/rustdesk/rustdesk.git

# ۲. برندسازی موسسه را اعمال کنید (ظاهر + نام + بسته‌ها)
bash run.sh ../rustdesk --full
```

سه سطح تغییر در دسترس است:

| فرمان | نتیجه |
|---|---|
| `bash run.sh ../rustdesk` | نام، آیکون و لوگو |
| `bash run.sh ../rustdesk --ui` | به‌علاوه پنل اختصاصی و رنگ‌های موسسه |
| `bash run.sh ../rustdesk --full` | همه‌چیز، شامل نام فایل اجرایی و شناسهٔ بسته‌ها |

سپس برای ساخت فایل نصبی:

```bash
cd ../rustdesk
python build.py --portable --flutter --hwcodec
```

خروجی: یک فایل نصبی که نام و آیکون موسسه رویش است.
جزئیات کامل در `docs/2-build-windows.md` نوشته شده است.

## دو و نیم: تصمیم دربارهٔ لوگو

پس از بررسی در اندازهٔ واقعی رابط کاربری، مشخص شد قاب لوگو در برنامه حداکثر
۳۰۰ در ۶۰ پیکسل است و متن نام در آن اندازه ریز و ناخوانا می‌شد. بنابراین:

| فایل | محتوا | کاربرد |
|---|---|---|
| `logo.png` و `logo_dark.png` | فقط نشان شمسه | داخل برنامه |
| `logo_300x60.png` | فقط نشان، دقیقاً هم‌اندازهٔ قاب برنامه | پیش‌نمایش |
| `logo_full.png` | نشان + نام موسسه | اسناد، سرصفحه، پاورپوینت، فایل نصبی |
| `emblem.png` | نشان خالص با رنگ رسمی | مهر، سربرگ، اسناد اداری |

نام برنامه در نوار بالای پنجره و در عنوان پنجره به‌هر‌حال نمایش داده می‌شود،
پس نبودنش در لوگو چیزی را از دست نمی‌دهد.

نکتهٔ فنی: نشان داخل آیکون برنامه ۱۰ درصد ضخیم‌تر از هندسهٔ رسمی لوگو ترسیم شده
است، چون در ۱۶ و ۲۴ پیکسل خطوط نازک محو می‌شدند. هندسهٔ اصلی لوگو در فایل‌های
اسناد دست‌نخورده مانده است.

## سه: چه چیزی عوض می‌شود

نام نمایشی برنامه در پنجره‌ها و فهرست برنامه‌ها، عنوان پنجره، نام و توضیح فایل
اجرایی، نام محصول در فایل نصبی، آیکون‌ها در ویندوز و مک و لینوکس و اندروید و آی‌اواس،
لوگوی داخل برنامه، نام بستهٔ اندروید و آی‌اواس، فایل خدمت و میان‌بر لینوکس،
و نشان لینک عمیق.

سطح تغییرات در دو حالت:

- `bash run.sh ../rustdesk` — برندسازی پایه؛ نام فایل اجرایی دست‌نخورده می‌ماند.
- `bash run.sh ../rustdesk --full` — نام فایل اجرایی هم به `nrisp-remote` تغییر می‌کند.

## چهار: چه چیزی عوض نمی‌شود و چرا

شناسه‌های داخلی کد، راه‌انداز نمایشگر مجازی، موتور تصویر و لایهٔ امنیت دست‌نخورده
می‌مانند؛ چون تغییر آن‌ها هیچ سود ظاهری ندارد و برنامه را از کار می‌اندازد.
همچنین عبارت پایین پنجره که به سازندهٔ اصلی اشاره می‌کند باقی می‌ماند، چون شرط
پروانهٔ نرم‌افزار است. توضیح کامل در `docs/3-legal-and-notes.md`.

# مرحله دو: ساخت نسخهٔ ویندوز با لوگو و نام شرکت شما

این راهنما از روی همان فرایندی نوشته شده که خودِ سازندگان راست‌دسک استفاده می‌کنند.
هدف: رسیدن به یک فایل نصبی که نام، آیکون و سرور شرکت شما داخلش باشد.

---

## ۰. خلاصهٔ کار

```
نصب ابزارها  →  گرفتن سورس  →  برندسازی با اسکریپت  →  ساخت  →  فایل نصبی
```

زمان تقریبی: دو تا سه ساعت بار اول (بیشترش نصب ابزارها و بار اول کامپایل است).

---

## ۱. ابزارهای لازم روی ویندوز

| ابزار | توضیح |
|---|---|
| Visual Studio 2022 Community | هنگام نصب، گزینهٔ Desktop development with C++ را تیک بزنید |
| Rust | از سایت rustup نصب کنید؛ نسخهٔ پایدار |
| Git for Windows | همراه Git Bash؛ همهٔ فرمان‌ها را در Git Bash بزنید نه در cmd |
| LLVM | نسخهٔ ۱۵ توصیه می‌شود؛ متغیر محیطی `LIBCLANG_PATH` را روی پوشهٔ bin آن بگذارید |
| vcpkg | کتابخانه‌های تصویر و صدا با آن نصب می‌شوند؛ متغیر `VCPKG_ROOT` را تنظیم کنید |
| Flutter | نسخهٔ ۳.۲۴.۵ (همان نسخه‌ای که پروژه استفاده می‌کند) |
| Python 3 | برای اسکریپت برندسازی و بسته‌بندی؛ به‌همراه `pip install pillow` |

یک نکتهٔ مهم: پروژه از یک موتور سفارشی فلاتر استفاده می‌کند. اگر فقط فلاتر عادی را
نصب کنید، ساخت ممکن است شکست بخورد. فایل موتور آماده را دانلود و جایگزین کنید:

```
https://github.com/rustdesk/engine/releases/download/main/windows-x64-release.zip
```

محتوای این فایل را در مسیر زیر کپی کنید (مسیر نصب فلاتر شما ممکن است متفاوت باشد):

```
<مسیر فلاتر>\bin\cache\artifacts\engine\windows-x64-release\
```

---

## ۲. گرفتن سورس

در Git Bash:

```bash
git clone --depth 1 --recurse-submodules https://github.com/rustdesk/rustdesk.git
cd rustdesk
```

دقت کنید `--recurse-submodules` را جا نیندازید؛ یکی از بخش‌های کد در زیرشاخه است
و بدون آن، ساخت شکست می‌خورد.

---

## ۳. نصب کتابخانه‌های سی‌پلاس‌پلاس

```bash
export VCPKG_ROOT=/c/vcpkg
$VCPKG_ROOT/vcpkg install --triplet x64-windows-static --x-install-root="$VCPKG_ROOT/installed"
```

این مرحله طولانی است (ممکن است نیم ساعت طول بکشد) چون کتابخانهٔ تصویر و صدا از
صفر کامپایل می‌شود. فقط یک بار لازم است.

---

## ۴. برندسازی

فایل `branding/branding.json` را باز کنید و مقادیر شرکت خودتان را بگذارید:

```json
{
  "app_name_en": "NRISP Remote Access",
  "app_name_fa": "دسترسی راه دور موسسه",
  "exe_name": "nrisp-remote",
  "company_en": "NRISP",
  "company_fa": "موسسه تحقیقات سیاست علمی کشور",
  "app_identifier": "ac.ir.nrisp.remote",
  "url_scheme": "nrisp",
  "server": "",
  "public_key": "",
  "colors": { "primary": "#0E3091", "accent": "#E89B25" }
}
```

این مقادیر از قبل برای موسسه تنظیم شده‌اند و نیازی به تغییر ندارند.
`server` و `public_key` عمداً خالی‌اند تا از سرور عمومی راست‌دسک استفاده شود.

نکته‌ها:

- `app_name_en` همان چیزی است که روی پنجره و در فهرست برنامه‌های ویندوز دیده می‌شود.
- `exe_name` نام فایل اجرایی است؛ بهتر است انگلیسی، کوتاه و بدون فاصله باشد.
- `url_scheme` برای لینک عمیق است؛ باید فقط حرف و رقم انگلیسی باشد.
- اگر سرور و کلید را خالی بگذارید، اسکریپت آن دو مورد را رد می‌کند و بعداً هم می‌توانید اضافه کنید.

سپس اجرا کنید (پایتون لازم است و `pip install pillow`):

```bash
cd <پوشه‌ی این پروژه>
bash run.sh ../rustdesk
```

خروجی، یک گزارش خط‌به‌خط است. عبارت `[!]` یعنی آن مورد پیدا نشد؛ معمولاً یعنی
نسخهٔ سورس عوض شده و باید دستی بررسی شود. `[-]` یعنی عمداً رد شده است.

برای تغییر نام فایل اجرایی هم، که برای ظاهر شرکتی لازم است:

```bash
bash run.sh ../rustdesk --full
```

این گزینه فایل اجرایی را از `rustdesk.exe` به نام شرکت شما تغییر می‌دهد و همهٔ
ارجاع‌های داخلی را هم اصلاح می‌کند. چون ساخت باید یک بار آزمایش شود، جداگانه گذاشته شده است.

---

## ۵. ساخت

در همان Git Bash، داخل پوشهٔ سورس:

```bash
python build.py --portable --flutter --hwcodec
```

- `--portable` یعنی فایل نصبی یکپارچه (self-extracting) بسازد.
- `--flutter` یعنی رابط کاربری جدید فلاتر استفاده شود.
- `--hwcodec` رمزگذاری سخت‌افزاری تصویر را فعال می‌کند؛ برای سرعت بهتر روی ویندوز.

خروجی در ریشهٔ پوشهٔ سورس ساخته می‌شود، چیزی شبیه:

```
rustdesk-1.5.0-install.exe      ← و اگر --full زده باشید، با نام شرکت شما
```

بار اول ممکن است بیست تا چهل دقیقه طول بکشد.

---

## ۶. ساخت فایل نصبی ام‌اس‌آی (اختیاری)

برای نصب گروهی روی چند سیستم، نسخهٔ MSI بهتر است چون می‌شود آن را با اکتیو دایرکتوری
یا گروه‌پالیسی پخش کرد. به WiX نیاز دارد:

```bash
cd res/msi
python preprocess.py --arp -d ../../rustdesk
msbuild msi.sln -p:Configuration=Release -p:Platform=x64
```

نام محصول در MSI از نام فایل اجرایی گرفته می‌شود، پس اگر `--full` زده باشید،
خودکار نام شرکت شما می‌شود.

---

## ۷. اگر ساخت شکست خورد

| نشانه | علت و راه‌حل |
|---|---|
| شکست در کتابخانهٔ تصویر | مطمئن شوید `VCPKG_ROOT` درست تنظیم شده و همان فرمان بخش ۳ را زده باشید |
| شکست در فلاتر | نسخهٔ فلاتر باید ۳.۲۴.۵ باشد و موتور سفارشی جایگزین شده باشد |
| شکست در `bindgen` یا `clang` | `LIBCLANG_PATH` تنظیم نشده است |
| پیام در مورد زیرشاخه | سورس را بدون `--recurse-submodules` گرفته‌اید |
| پیام در مورد `sciter.dll` | یعنی مسیر رابط کاربری قدیمی فعال شده؛ مطمئن شوید `--flutter` را زده‌اید |

خروجی خطا را برایم بفرستید تا دقیقاً بگویم کدام راه‌حل لازم است.

---

## ۸. نصب و آزمایش

۱. فایل نصبی را روی یک سیستم تست نصب کنید.
۲. برنامه باید با نام و لوگوی شرکت شما بالا بیاید.
۳. در پنجرهٔ برنامه باید آدرس سرور خودتان را ببینید.
۴. از یک سیستم دیگر با همان برنامه وصل شوید و ببینید تصویر و کنترل کار می‌کند.

اگر روی سیستم مقصد پنجرهٔ هشدار ویندوز باز شد، این طبیعی است و دلیلش در
[مرحله سه](3-legal-and-notes.md) توضیح داده شده است.

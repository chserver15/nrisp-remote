اگر لوگوی اختصاصی شرکت خود را دارید:
If you already have your company logo:

  یک فایل مربعی به نام icon.png در همین پوشه بگذارید.
  سپس اسکریپت generate_icons.py را اجرا کنید تا همه‌ی اندازه‌ها از آن ساخته شود.

  Put a square PNG named icon.png in this folder, then run generate_icons.py
  and every required size/format will be generated from it.
  Suggested size: 1024x1024 with transparent background.
